# 대전 퀴즈 게임

터미널(콘솔)에서 즐기는 파이썬 퀴즈 게임입니다. 퀴즈 풀기, 퀴즈 추가, 퀴즈 목록, 최고 점수 확인을 할 수 있고, 프로그램을 껐다 켜도 추가한 퀴즈와 최고 점수가 `state.json` 파일에 저장되어 유지됩니다.

## 프로젝트 개요

- 파이썬 기본 문법과 클래스(객체 지향)로 만든 터미널 퀴즈 게임입니다.
- `Quiz` 클래스는 퀴즈 한 문제를 표현하고, `QuizGame` 클래스는 게임 전체(메뉴, 풀기, 추가, 목록, 점수, 저장)를 관리합니다.
- 외부 라이브러리 없이 파이썬 표준 라이브러리(`json`, `os`)만 사용했습니다.
- Git으로 기능 단위 커밋을 남기고, 브랜치를 만들어 작업한 뒤 병합하며 GitHub에 공개했습니다.

## 퀴즈 주제와 선정 이유

- 주제: **우리 동네 대전**
- 선정 이유: 내가 사는 동네라서 문제를 직접 만들고 정답을 확인하기 쉽고, 퀴즈를 풀면서 대전의 이름, 음식, 지역, 역사를 다시 떠올려 볼 수 있어서 선택했습니다.

## 실행 방법

1. 준비물: Python 3.10 이상, Git
2. 저장소 내려받기

```bash
git clone https://github.com/wymm01/E1-2.git
cd E1-2
```

3. 프로그램 실행

```bash
python main.py
```

별도로 설치할 라이브러리는 없습니다.

## 기능 목록

- 메뉴: 번호로 기능 선택, 종료 기능 제공
- 퀴즈 풀기: 저장된 퀴즈를 차례로 출제하고 정답/오답을 알려 주며, 마지막에 결과를 보여 줌 (퀴즈가 없으면 안내)
- 퀴즈 추가: 문제, 선택지 4개, 정답 번호(1~4)를 입력받아 등록하고 바로 파일에 저장
- 퀴즈 목록: 등록된 퀴즈의 문제, 선택지, 정답을 보여 줌 (퀴즈가 없으면 안내)
- 점수 확인: 최고 점수를 확인하고, 퀴즈를 풀 때마다 비교해서 갱신 (아직 풀지 않았으면 안내)
- 파일 저장/불러오기: 퀴즈와 최고 점수를 `state.json`에 UTF-8로 저장하고 시작할 때 불러옴
- 입력 예외 처리
  - 앞뒤 공백 제거
  - 숫자가 아닌 입력, 허용 범위 밖 숫자, 빈 입력은 안내 후 다시 입력
  - `Ctrl+C`, 입력 스트림 종료(EOF)가 발생해도 저장 후 안전하게 종료
  - 데이터 파일이 없으면 기본 퀴즈로 시작하고, 손상되었으면 안내 후 기본 퀴즈로 초기화

## 데이터 파일 설명 (state.json)

- 경로: 프로젝트 루트의 `state.json` (`main.py`와 같은 폴더)
- 역할: 프로그램을 종료해도 퀴즈 목록과 최고 점수가 유지되도록 저장
- 인코딩: UTF-8
- 저장 시점: 퀴즈를 추가했을 때, 최고 점수가 생기거나 바뀌었을 때, 프로그램을 종료할 때
- 파일이 없거나 손상된 경우: 안내 메시지를 보여 주고 기본 퀴즈 5개로 시작(또는 초기화)

스키마:

| 키 | 타입 | 설명 |
|---|---|---|
| `quizzes` | 리스트 | 퀴즈 목록 |
| `quizzes[].question` | 문자열 | 문제 |
| `quizzes[].choices` | 문자열 리스트(4개) | 선택지 |
| `quizzes[].answer` | 정수(1~4) | 정답 번호 |
| `best_score` | 정수 또는 `null` | 최고 점수(맞힌 문제 수), 아직 풀지 않았으면 `null` |

예시:

```json
{
  "quizzes": [
    {
      "question": "대전의 옛 순우리말 이름은?",
      "choices": ["새벌", "한밭", "푸른들", "큰고을"],
      "answer": 2
    }
  ],
  "best_score": 5
}
```
